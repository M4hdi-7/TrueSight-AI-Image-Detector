# 1. Introduction

In March 2023, an AI-generated image of Pope Francis wearing a Balenciaga puffer jacket spread across social media as if it were real, fooling viewers in their millions. Two months earlier, fabricated images depicting the arrest of a former U.S. president had circulated under the same misimpression. By 2024, generative-image models — Midjourney, DALL·E, Stable Diffusion, Google Gemini's Imagen, and a long tail of open-source diffusion variants — had crossed the threshold beyond which the average human reader can no longer reliably distinguish their output from authentic photography. The implications cross domains: journalism cannot trust the photographs it receives; insurance companies cannot trust claim evidence; courts cannot trust photographic exhibits without provenance; and an ordinary person scrolling a feed has no easy way to ask the basic question: *is this real?*

A small industry of detection tools has emerged in response. Hive AI, Sightengine, Optic, AI or Not, Illuminarty, and several others offer cloud-based classifiers that ingest an image and return an AI-generated probability score. These services are useful but constrained in three ways. First, they are **cloud-only** — the image leaves the user's device, which is a non-starter for journalists handling source-protected material or for anyone working with private content. Second, they are **account-gated** and rate-limited, which makes ad-hoc use cumbersome. Third, they are **opaque verdicts** — they tell the user "this is 87% AI" without explaining *why*, and provide no auxiliary forensic evidence (metadata inspection, compression artefacts, source provenance signatures) that a sceptical user could weigh independently.

**TrueSight** is a graduation-project response to those constraints. It is a local-network web application that classifies user-uploaded images as AI-generated, deepfake, or authentic, and produces a forensic report explaining the verdict in plain language. The system orchestrates two commercial detection APIs (Sightengine and Hive AI) in a cost-aware cascade — Sightengine provides the primary AI-or-real probability and a deepfake (face-swap) score, while Hive is consulted only when Sightengine flags an image as AI, purely to extract per-engine attribution (which Sightengine's API plan does not return). On top of the API verdicts, TrueSight layers local on-device forensic signals — EXIF metadata inspection, JPEG quantization analysis, dimension and format validation — that run without network access and qualify the API verdict for the user.

The application runs on a user's personal computer over LAN. A phone or laptop on the same Wi-Fi can reach the web interface, drop an image, and receive a verdict within seconds. No login, no cloud account, no external storage of the image — the only data leaving the device is the image itself, sent to the detection APIs for classification. A local SQLite database remembers the user's past scans.

The project does **not** train its own neural network for AI detection. Training a competitive detector requires labelled examples spanning current generators (Midjourney v8, Gemini 3, Flux, GPT-Image v2) and evolves faster than any retraining cycle a student could maintain. An earlier prototype of this project (v1.0) did run five local PyTorch classifiers in an ensemble, but the resulting system was slow on consumer hardware and quickly outdated. The pivot to API-driven detection in v1.1, and the cascade architecture in v1.2, was an informed engineering choice — current detection from external providers, system design and forensic value-add from this project.

This dissertation documents the requirements, analysis, design, implementation, and evaluation of TrueSight. Chapter 2 sets out the objectives. Chapter 3 surveys comparable systems. Chapter 4 lists functional and non-functional requirements. Chapters 5 and 6 cover the analysis (use cases, activity diagrams) and design (architecture, data model) phases. Chapter 7 describes the implementation — tools, code organisation, scenarios, sample reports. The appendices contain the source code, screenshots, and the project deliverable.

The system was evaluated against a manually-curated test set of 59 images spanning twelve named AI generators and a representative selection of authentic photographs. It achieved 98.3% accuracy, 100% precision, 97.5% recall, and an F1 score of 98.7% on that set, with a single misclassification — a Reddit-sourced image whose original post explicitly identified it as a generation chosen for exceptional photorealism. The detailed evaluation appears in Chapter 7.
